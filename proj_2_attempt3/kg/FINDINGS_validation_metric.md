# The validation metric could not detect a change — and body site is not the lever

*Session of 2026-09-02. Code: `agreement_metric.py`, `body_site.py`,
`analyze_bodysite.py`, `analyze_bodysite_effect.py`. Results:
`agreement_metric.json`, `body_site.json`, `bodysite_effect.json`.*

---

## 1. Four "strong nulls" were a tautology, not a result

Four structural corrections have now been applied to this graph — screening 22
non-human / non-case-control papers, splitting rank placeholders off their
parents, and (today) restricting to gut evidence. Each was measured the same way:
McNemar's exact test on the pairs decisive against Disbiome and Peryton. Each
returned **zero flips, p = 1.00**, and the previous write-up recorded that as a
strong empirical finding — *"not an underpowered null — a true zero"*.

That reading is wrong, and the error is structural rather than statistical.

- A pair counts as **decisive** only when our edge is not contested.
- `contested = bool(n_up and n_down)`, so **every decisive edge is unanimous**.
  Verified directly: all 1,765 non-contested edges have a minority vote of
  exactly 0.
- Every one of these corrections only **removes** papers (or moves them to a new
  node key, which drops the pair out of the "decisive in both" set).
- A unanimous edge that loses papers stays unanimous, in the same direction.

**Therefore no pair decisive in both variants can ever flip, for any
paper-removal correction whatsoever.** The zero was guaranteed before any data
was collected. A p-value of 1.00 from a test that cannot return anything else is
not evidence of no effect.

The data behaves exactly as the argument predicts. Across the gut restriction,
17 edges change their `direction` field — and every single one is a
contested↔decisive transition. Not one is enriched↔depleted.

This matters beyond bookkeeping: the project has spent two sessions asking "did
this correction recover agreement with the curated databases?" using an
instrument that is incapable of answering. **Disbiome/Peryton decisive-pair
agreement should not be used to evaluate data-quality changes.** It remains a
reasonable validity check on the graph as a whole.

## 2. A metric that can move

`agreement_metric.py` replaces the binary with the **signed strength** of our
evidence, rather than thresholding it first:

```
s = (n_up − n_down) / (n_up + n_down)        ∈ [−1, +1]
c = s × r        where r = +1/−1 is the curated database's direction
```

`c` is +1 when every paper we hold agrees with the reference, −1 when every paper
contradicts it, and moves continuously in between. Dropping one oral paper from a
12-up/1-down edge moves that edge from 0.846 to 1.0 — a change the binary metric
is blind to by construction.

The null is generated by **paper-level resampling**: drop the same *number* of
papers at random, 2,000 times, and recompute. Paper-level because observations
are not independent — one paper contributes to many pairs — and because it asks
the question that matters: is *this* set of papers unusual, or would any set of
that size do the same?

The script refuses to run unless its in-memory tally reproduces `graph.json`
exactly. That check earned its keep immediately (§4).

It is demonstrably sensitive where the old metric was blind: the gut restriction
moves **16 of 242** Disbiome pairs and **19 of 188** Peryton pairs, where McNemar
saw 0.

## 3. Both paper-removal corrections, re-tested — both honest nulls

| correction | source | pairs | moved | observed Δ | min. detectable | p |
|---|---|---:|---:|---:|---:|---:|
| drop 6 non-gut papers | Disbiome | 242 | 16 | **−0.0073** | 0.0093 | 0.120 |
| drop 6 non-gut papers | Peryton | 188 | 19 | **−0.0048** | 0.0119 | 0.285 |
| MAIN_DATA screen (22 papers) | Disbiome | 250 | 2 | **+0.0015** | 0.0174 | 0.852 |
| MAIN_DATA screen (22 papers) | Peryton | 202 | 3 | **+0.0043** | 0.0185 | 0.620 |

These are now **nulls with power statements** rather than tautologies. Neither
correction moves agreement, and an effect smaller than ~0.01 (non-gut) or ~0.018
(screen) in mean concordance cannot be resolved at this corpus size.

Note the sign. The body-site restriction moves concordance **down**, the opposite
of the hypothesis that oral studies were dragging agreement down by being scored
against gut-weighted databases. The screen moves it up, but at p = 0.85 and
p = 0.62, and only 2–3 pairs move at all — consistent with the earlier finding
that 18 of the 22 screened papers produced no usable extraction.

**Both corrections remain justified on construct validity, and neither should
ever be cited as an accuracy improvement.** That conclusion is unchanged from the
previous session; what has changed is that it now rests on a test that could have
falsified it.

## 4. Body site: measured, and rejected as an edge key

Body site was the top lever out of the adjudication — the claim being that edges
pool papers from different sampling sites onto one node, manufacturing false
contradictions with the gut-weighted curated databases.

**The gap had to be closed first.** `metadata.jsonl` only ever covered the
original 250 papers; 70 of the 281 contributing papers had no `body_site` at all.
`body_site.py` fills it with a keyword scan rather than an LLM pass, because the
sampled site is stated almost verbatim in Methods — and, unlike an LLM pass, a
scanner can be *scored* before it is trusted:

- argmax over site cues: **84.3%** against the independent LLM labels. Its
  dominant error was not context noise but **co-sampling** — stool studies read
  as blood, because they draw serum for metabolomics.
- tightening the context window made it *worse* (83.5%, 79.9%) by converting
  those errors into `unknown`.
- **any stool cue wins outright: 92.4%** — and that is also the rule the question
  needs, since what matters is whether the microbiome was measured in stool.

Result over all 281 contributing papers: **274 stool, 4 oral, 1 nasal, 1 blood,
1 gut biopsy** — no unknowns left. The corpus is **97.9% gut**.

Six non-gut papers, but they are disproportionately prolific: **103 of 1,985
edges (5.2%) carry non-gut evidence, 58 of them mixed with stool**. So the
exposure is larger than the paper count suggests — and unlike the earlier
corrections, the ceiling was genuinely non-zero (10 of 167 decisive Disbiome
pairs, 24 of 136 Peryton pairs).

It still comes out null (§3). **Recommendation: do not key edges on body site.**
With 6 non-gut papers, keying would fragment 58 mixed edges into singletons to
separate evidence that does not measurably matter. Site now ships as an edge
**attribute** (`sites`, `gut_only`) so a consumer can filter to gut-only evidence
— which was the part actually worth having. 1,882 edges are gut-only.

**Correction to the record:** the adjudication recorded *Rothia*/Parkinson's as
"both our papers are saliva studies". It is one oral paper and one stool paper.

## 5. Two bugs found by verifying rather than reading

**(a) The placeholder fix was erasing itself on every rebuild.** Rebuilding
`graph.json` without the NCBI taxdump — which is the only mode available in this
environment, the network policy denies `ftp.ncbi.nih.gov` — silently undid the
2026-09-01 rank-placeholder split while printing a successful build with
`"split_placeholders": true` and `"n_placeholder_nodes": 0`. `taxonomy_cache.py`
skips any node without a taxid, and a placeholder deliberately has none, so all
96 placeholder strings became cache misses and took the string-folding path: no
placeholder flag, no containment link, and spelling variants split apart. Cost of
one rebuild: 77 placeholder nodes → 0, 670 containment links → 610, 892 taxa →
909. Fixed by recovering the parent from the containment link the node already
carries, or by replaying the taxdump's qualifier-trimming rule. Two guards came
out of diffing the rebuild against the committed graph rather than trusting it: a
**phage is not a member of the genus it infects** (naive trimming hung
*Escherichia virus JES2013* under *Escherichia*), and brackets must be stripped.
The rebuild now reproduces the committed graph exactly and is a **fixed point** —
a second rebuild on top of the first is identical, so it can no longer erase
itself.

**(b) Edge weight counted observations, not papers.** `build_kg.py` carried the
comment *"papers, not observations: the same paper naming a taxon twice is one
vote"* directly above code that applied that dedup to `papers` and `evidence` but
**not** to `n_up`/`n_down` — the fields that drive `direction`, `contested`,
`consistency`, and the edge weight the graph is documented to carry. Found
because the permutation test's in-memory tally disagreed with `graph.json` on 42
edges. Cause: papers listing the same taxon twice (*"Coriobacteriaceae,
Coriobacteriaceae"*; *"Ruminococcus"* and *"Ruminococcus sp"* folding to one
taxid) — 48 cases over 44 of 1,985 edges (2.2%). No duplicate paper rows exist.
Contested status changes on zero edges and the decisive set is bit-identical, so
external agreement is untouched — but **7 already-contested edges change their
majority label**, including *Bacteroides*/Parkinson's going depleted → enriched
(4,5 → 4,3) because one paper listed it as depleted twice.

## 6. What this implies for the next session

1. **Re-examine any past claim measured with decisive-pair agreement.** The
   instrument cannot see paper-removal effects. The headline
   Disbiome/Peryton rates (71.9% / 72.8%) are still fine as a validity check.
2. **Body site is closed.** Labelled, measured, null, shipped as an attribute.
   Do not spend more on it.
3. **The remaining lever with actual power is corpus size**, not further
   structural correction. Three corrections in a row have now moved agreement by
   an amount smaller than this corpus can resolve, and the minimum detectable
   effect (~0.01–0.02 mean concordance) is set by n, not by the metric.
4. **`relation_sentences.json` still covers only the original 250 papers**, not
   the current 326 — still the prerequisite for the embedding work, and still
   why 2 of the 14 doubly-contradicted pairs could not be adjudicated.
