✓ 1 It is the FULL paper, not an abstract or landing page

A row only qualifies if the text we read is ≥ 40,000 characters — the length of a real paper body.

Measured across the 3,236: min 40,018   median 52,550   mean 56,070   max 210,205 chars. An abstract is ~1,000–3,000 chars — it is structurally impossible for one to enter this set.

Rows where the link resolved to an abstract, paywall stub, or a short/partial read were excluded → sent to needs-review, never counted as empty.

✓ 3 Scanned for EVERY accession type — then swept twice more for the ways a regex fails

Primary pass — 20 repository patterns: BioProject BioSample SRA/ENA/DDBJ GEO dbGaP EGA PRIDE MetaboLights GSA GSA-Human CNGB NODE MG-RAST ArrayExpress BioStudies figshare Zenodo Dryad …

Independent sweep #1 — whitespace-split

Catches codes a plain regex can't see, e.g. PRJNA 795467 split by a PDF line-break. Requires deposit language nearby.

Independent sweep #2 — lookalike-collision

Recovers a real code the filter wrongly dropped for sitting near a word like catalog / primer (e.g. an EGA id beside "Polygenic Score Catalog").

Every hit these two sweeps surfaced was hand-checked; the real ones were merged as codes. The 483 browser-read rows were scanned by the tolerant extractor that bakes both sweeps in — so they cannot repeat those misses.

± the honest limit

This is a measured floor, not a proof. Audit of 1,853 rows: the loose detector raised 127 candidates — 110 were provable non-codes (the journal "Cancers" fused to a page number, grant/ethics numbers), 8 were genuine misses, all fixed. 8 / 1,853 = 0.43% → ~99.6% clean. A residual ~0.4% (order ~10–15 codes corpus-wide) could hide in unusual phrasing only a human read would catch.
